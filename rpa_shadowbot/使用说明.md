# 影刀 RPA 备选模式（无人值守）

本目录存放**从影刀应用内导出的 v1.0 对账代码副本**。v2.0 起，影刀已从主链路退出，
对账主入口是 `engine/` 包（网页 / 命令行）。影刀仅保留一个不可替代的场景：

> **无人值守**：定时自动对账、监听财务共享文件夹的新文件、跑完自动推送结果——
> 即"没人点网页按钮"的场景。

## 文件说明

| 文件 | 说明 |
|---|---|
| `cross_check.py` | v1.0 影刀内嵌对账引擎原样副本（依赖 xbot/package 环境，含 `Cross_Check` 类） |
| `config.py` | v1.0 影刀入口参数配置原样副本 |

> 注意：这两份是**历史存档**，只能在影刀应用内运行（依赖 `xbot` 包）。
> 主流程请使用 `engine/`（`python -m engine --help`）。

## 启用影刀模式的步骤（v2.0 备选）

1. 影刀 RPA 中新建/打开应用，把本目录两份 py 作为"Python 模块"导入（或使用原应用内嵌版本）
2. 配置「文件夹触发」指令，监听约定的共享文件夹（如财务导出 CSV 的目录）
3. 触发后调用模块 `main(args)`，参数与 v1.0 相同：
   `{"AI开关": 0|1, "文件地址": "业务根目录"}`
4. 产出：`output/对账差异_*.xlsx` + `task/task_*.json` 状态回执（v1.0 行为）

## 与主流程的关系

| | 主模式（默认） | 影刀模式（备选） |
|---|---|---|
| 触发方式 | 网页按钮 / 命令行 | 文件夹监听 / 定时调度 |
| 执行代码 | `engine/` 独立引擎 | 本目录影刀内嵌代码 |
| 结果位置 | `data/tasks/{task_id}/` | `output/` + `task/` |
| 依赖 | Python + pip 依赖 | 影刀 RPA 客户端 |
| 适用 | 人机交互（财务主动使用） | 无人值守（零人工操作） |

同一套对账规则在两处实现（`engine/checks.py` 与本目录 `cross_check.py`），
如修改对账规则，需**两处同步**（或改用 Windows 计划任务 + `python -m engine` 替代影刀模式，
则只需维护 `engine/` 一份）。
