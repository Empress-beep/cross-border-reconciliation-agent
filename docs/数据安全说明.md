# 数据安全说明

对齐《项目改造说明》§九。核心结论：**真实业务数据不出内网，出网的只有两类已脱敏内容与 API 凭证调用。**

## 一、数据流向图

```
浏览器 ── multipart ──► 本机 Flask ──► data/tasks/{task_id}/raw/     【本地，不出网】
                            │
                            ▼
                     engine 规则对账 ──► output/对账差异_*.xlsx      【本地，不出网】
                            │          meta.json（状态+摘要）        【本地，不出网】
                            │
            ┌───────────────┴────────────────┐
            │ ai_enabled=1（勾选时才出网）      │ 结果页聊天（提问时才出网）
            ▼                                ▼
   脱敏归因请求 ──HTTPS──► 千问 API     脱敏差异上下文 ──HTTPS──► FastGPT
   （单号掩码+金额区间化）               （同样脱敏，经服务端代理）
            │                                │
            └──────── 备注/回答只回流到本地页面，原始数据不随行 ┘
```

- 所有出网都是**出站 HTTPS**：本机不需要公网 IP、不需要内网穿透、不开放任何入站端口
- API Key 只存本机 `.env`，由 Flask 服务端使用，**不进浏览器、不进日志、不进文档**

## 二、出网清单（穷举）

| # | 触发条件 | 目的地 | 出网内容 | 脱敏 |
|---|---|---|---|---|
| 1 | 对账时勾选「启用AI差异分析」 | `dashscope.aliyuncs.com`（千问） | 逐条差异：对账状态 + 行字段（`sanitize_row` 规整后）+ 脱敏提示语 | ✅ 订单号掩码、金额区间化 |
| 2 | 结果页聊天框发送消息 | `cloud.fastgpt.cn`（FastGPT） | 本批差异摘要文本（统计+构成+每表最多 8 行明细）+ 用户问题 | ✅ 同上，且超 4000 字截断 |
| 3 | `.env` 配置了 FastGPT 时前端加载 | 无额外出站 | 仅访问本机 Flask | — |

**不出网**：原始 CSV、差异 Excel、meta.json、run.log/app.log、任务历史、`.env` 明文 Key、页面展示的任何原始数据（页面数据全部来自本机）。

## 三、脱敏规则（出网前强制执行）

| 规则 | 示例 |
|---|---|
| 订单号/结算单号掩码（三段结构保头尾） | `AMZ-20260904-007` → `AMZ-****-007` |
| 无分段单号首尾保留 | `TEMU-902003` → `TE********03` |
| 金额区间化（步长 10） | `34.54` → `[30,40)`；`-10.80` → `[-20,-10)` |
| 识别字段名自动覆盖 | 含 `amount/fee/amt/commission/总额/金额/手续费/到账` 的列全部区间化；含 `单号/编号/_id/_no` 的列全部掩码 |

覆盖实现：`engine/desensitize.py`（`mask_id` / `bucket_amount` / `sanitize_row` / `build_diff_context`）。
回归保障：`tests/test_ai.py` 断言出网 payload **不含完整单号与精确金额**；`tests/test_chat.py` 断言聊天上下文同样合规——测试挂了就发不出去。

## 四、本机数据留存位置

| 数据 | 路径 | 保留策略 |
|---|---|---|
| 上传的原始 CSV | `data/tasks/{task_id}/raw/` | 随任务保留，可整目录删除 |
| 差异 Excel | `data/tasks/{task_id}/output/` | 同上 |
| 任务元数据 | `data/tasks/{task_id}/meta.json` | 同上（删除后历史列表/下载失效） |
| 双日志 | `data/logs/app.log`、`data/tasks/{task_id}/run.log` | app.log 滚动 1MB×5 自动清理 |
| API Key | `.env`（本机明文） | 换机随目录拷贝；勿发到聊天工具/仓库 |

## 五、边界与责任

- 局域网模式（`--host=0.0.0.0`）下，**同一局域网内**任何可访问该 IP 的人都能用上传/下载功能——共享范围 = 防火墙放行的网络范围；v2.1 规划了登录鉴权
- FastGPT 云端知识库中的 `跨境对账规则文档.md` 只含业务规则，不含任何真实订单数据
- 聊天请求会带 `chatId=task_id`（形如 `task_20261024_111835_9d14`），属任务编号而非业务数据
