# 部署手册

适用版本：v2.0（2026-10）。目标场景：单机自用 / 局域网共享 / 换机迁移。

## 一、本机部署（四步）

```bash
# 1. 环境：Python 3.10+，进入本项目目录，安装依赖
pip install -r requirements.txt

# 2. 基础服务（必需）：安装并启动 MySQL 8.0+ 与 Redis 4.0+
#    Windows 下 Redis 推荐 5.0.14（tporadowski 版，装为系统服务）
#    数据库 reconcile_agent 与任务表首次启动时自动创建，无需手工建库

# 3. 配置：复制模板，按需修改连接参数（默认本机 127.0.0.1，root/3306/6379 无密码）
copy .env.example .env
#    MYSQL_HOST/PORT/USER/PASSWORD/DB、REDIS_HOST/PORT/DB、QUEUE_NAME
#    可选：DASHSCOPE_API_KEY（千问归因）
#    可选：FASTGPT_BASE_URL / FASTGPT_API_KEY / FASTGPT_APP_ID（聊天面板）

# 4. 启动（Web 进程会自动拉起 RQ worker 子进程与看门狗，无需单独启动 worker）
python app.py
```

浏览器打开 `http://127.0.0.1:8765` → 点「一键填充示例数据」→ 开始对账，
预期产出 **9 处差异**（订单侧 4 + 回款侧 5）。

也可以直接双击 `启动_本机.bat`（等价于第 3 步）。

## 二、局域网部署（同机，供同事访问）

```bash
# 方式一：双击 启动_局域网.bat
# 方式二：命令行
waitress-serve --host=0.0.0.0 --port=8765 app:app
```

- 同事访问 `http://本机IP:8765`（本机 IP 用 `ipconfig` 查看，IPv4 地址）
- 首次使用若访问不通，检查 Windows 防火墙是否放行 **8765 端口**：
  `控制面板 → 系统和安全 → Windows Defender 防火墙 → 允许应用通过防火墙`
- 局域网模式使用 waitress 生产服务器，不走 Flask 开发服务器

## 三、换机 / 服务器部署

1. 整个**项目目录原样拷贝**到目标机器（示例数据已内置 `data/sample/`，不依赖外部路径）
2. 目标机安装 Python 3.10+，执行 `pip install -r requirements.txt`
3. 目标机安装并启动 MySQL 与 Redis；迁移任务表：旧机
   `mysqldump reconcile_agent > tasks.sql` → 新机 `mysql reconcile_agent < tasks.sql`
4. 带上 `.env`（含 API Key 与 MySQL/Redis 连接参数）；没有 `.env` 则 AI 降级，其余功能不受影响
5. 启动：本机用 `python app.py`；作为局域网/服务器用 `启动_局域网.bat` 或
   `waitress-serve --host=0.0.0.0 --port=8765 app:app`
6. 验证：浏览器开首页 → 一键示例 → 结果页 9 处差异 → Excel 可下载

`data/tasks/`（原始 CSV、Excel、任务日志）随目录一起迁移；**历史任务列表存在 MySQL `tasks` 表**，需按第 3 步单独迁移，否则历史列表为空（对账功能不受影响）。

## 四、端口问题

| 情况 | 处理 |
|---|---|
| 8765 被占用 | 换端口启动：`python app.py --port 8770` 或 `waitress-serve --host=0.0.0.0 --port=8770 app:app` |
| 查占用 | `netstat -ano | findstr :8765` → 记下 PID → `tasklist /fi "pid eq <PID>"` |
| 忘了参数 | `python app.py --help` |

## 五、部署后验证清单

- [ ] 首页 `http://127.0.0.1:8765` 正常打开，历史任务列表可见
- [ ] 一键示例 → 对账成功 → 9 处差异 → 双 sheet Excel 可下载
- [ ] `data/logs/app.log` 有本次启动的「Web 服务初始化完成」记录
- [ ] `data/logs/worker_console.log` 有「RQ worker」初始化与消费记录（无 Redis/MySQL 连接报错）
- [ ] （配了 key 时）勾选 AI 差异分析 → 备注列有 ≤30 字归因
- [ ] （配了 FastGPT 时）结果页出现「Agent 问答」聊天框
